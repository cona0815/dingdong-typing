# 叮咚打字島

中年級英文＋注音打字練習網頁（單檔 HTML，開啟 `index.html` 即可使用）。

- 版本：v1.20　日期：2026-10-07（原名：注音小手指）
- 16 關：英文打字 5 關 → 注音鍵位 8 關 → 注音拼音實戰 3 關
- 手指彩色鍵盤、導引線、可開關的手部圖示
- 叮咚逐格動畫、太鼓式連擊回饋、音效與背景音樂
- 進度只存在使用者自己的瀏覽器（localStorage），不蒐集任何個人資料

## 檔案

| 路徑 | 說明 |
| --- | --- |
| `index.html` | 遊戲本體，圖片、音效、音樂都已內嵌，單檔即可離線使用 |
| `assets/` | 原始素材：叮咚動畫序列圖、音效、背景音樂 |
| `tools/` | 音效合成與動畫圖正規化的 Python 腳本 |

## 開啟 GitHub Pages

Settings → Pages → Branch 選 `main`、資料夾選 `/ (root)` → Save，約一分鐘後網址為
`https://<帳號>.github.io/<repo 名稱>/`。
